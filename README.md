# 🎓 EduPrediction System

AI-Based Early Warning System for Student Academic Performance and Risk Prediction

---

##  Project Overview

EduPrediction uses Machine Learning to predict whether a student is:

- ✅ Low Risk
- ⚠️ Medium Risk
- 🚨 High Risk

The system analyses student information and predicts academic risk using a trained Random Forest model.

---

##  Features

- Student Risk Prediction
- Interactive Streamlit Dashboard
- Academic Recommendations
- AI-Based Assessment
- Random Forest Machine Learning Model

---

##  Technologies Used

- Python
- Visual Studio Code
- Streamlit
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

---

##  Model Accuracy

**83.08%**

---

##  Dataset

Dataset Used:

`student-por.csv`

The dataset contains:

- Student demographics
- Study behaviour
- Academic performance
- Family support information
- School support information

---

##  Running The System

Install dependencies:

```bash
py -m pip install -r requirements.txt
```

Run the dashboard:

```bash
py -m streamlit run dashboard/app.py
```
